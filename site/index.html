Contribution Waveform

GitHub contribution history as a continuous waveform instead of a grid of squares. Regenerated daily by a scheduled Action and served as a self-contained SVG, so it renders inside a profile README.

Embed snippets

The <picture> form adapts to the reader's GitHub theme. The Markdown form is simpler but locks to one theme.

Use this for your own account

  1. 1. Fork this repository.
  2. 2. Set username in waveform.config.json to your GitHub handle.
  3. 3. Add a repository secret named GH_PAT — a classic PAT with the read:user scope.
  4. 4. Enable Pages with GitHub Actions as the source, then run the workflow once by hand.
Built with TypeScript and no charting library. Images are proxied and cached by GitHub's camo for a few hours, so a README embed updates about once a day.

How it works

A scheduled Action queries the GitHub GraphQL API year by year, caches the result to data/contributions.json, and renders six SVG files.

The soft band is your rolling 30-day average. The thin line is the 7-day average. The wave is your actual daily count, smoothed with a Catmull-Rom spline. The accent fill marks days above your 30-day average; the muted fill marks days below it.

The Y axis is scaled to the 98th percentile rather than the maximum, so a single 200-commit day cannot flatten the rest of the year.
